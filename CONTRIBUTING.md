# Contributing to Ghost Labour Busters

Thank you for helping make the developer and freelancer community safer.

## Ways to contribute

1. **Report an incident** — Use the [report template](../../issues/new?template=report-ghost-labour.yml).
2. **Improve the guide** — Open a pull request to refine red flags, protection tips, or wording.
3. **Suggest patterns** — If you notice a recurring tactic not yet listed, open an issue describing the pattern (no personal details).
4. **Share the repo** — Star it and share with communities so more people can stay safe.

## Rules for all contributions

- **No doxxing.** Never post personal phone numbers, private emails, home addresses, government IDs, or unredacted screenshots containing them.
- **Facts only.** Describe observable behaviour and outcomes. Avoid assumptions about motives or identity.
- **No harassment or brigading.** This is not a place to target individuals.
- **Privacy first.** Redact all sensitive information before uploading evidence.
- **Stay constructive.** Focus on patterns and safety practices that help others.

## Pull request process

1. Fork the repository.
2. Make your changes on a new branch.
3. Keep the tone educational and neutral.
4. Open a pull request with a clear description of what you improved and why.

We will review PRs as quickly as possible. Thank you for contributing responsibly.
