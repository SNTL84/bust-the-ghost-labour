# 💀 Bust the Ghost Labour

> **Anonymous developer networks that hide identities while chasing paid projects through WhatsApp, Telegram, Discord, SMS & more.**

This repository is a **community-driven list** dedicated to exposing and documenting "Ghost Labour" practices in the developer ecosystem.

### What is Ghost Labour?

Ghost Labour refers to the practice where developers (or intermediaries):
- Connect with each other **anonymously**
- Continuously ask for feedback, reviews, or collaboration **without revealing their real identities**
- Use private channels like **WhatsApp, Telegram, Discord, SMS, Signal**, etc.
- Ultimately try to **enroll people into paid projects**, gigs, or "opportunities" while staying hidden

These patterns can lead to:
- Unreliable collaborations
- Payment disputes
- Scams or ghosting after work is done
- Loss of trust in the developer community

## 📝 How to Report

Please open an **Issue** with the following details (keep identities protected if needed):

- Platform used (WhatsApp / Telegram / Discord / SMS / etc.)
- Type of activity observed
- How the anonymity was maintained
- Outcome (ghosting, unpaid work, pressure for paid projects, etc.)
- Any red flags others should watch for

You can also reach out privately via the contacts below.

---

## 🛡️ Stay Safe Tips

- Prefer transparent, identity-verified platforms for paid work
- Never start significant work without clear contracts and milestones
- Be cautious of people who refuse to share LinkedIn / GitHub / portfolio while pushing paid opportunities
- Use escrow or platform-protected payments when possible
